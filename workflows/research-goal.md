# Research `/goal`

Paste and adapt the hypothesis identifier:

```text
/goal Take preregistered hypothesis <HYPOTHESIS_ID> through the governed research lifecycle and finish with an evidence-backed state of PROMOTED, REJECTED, INCONCLUSIVE, or INVALID. The hypothesis definition, primary metric, universe, expected sign, test period, and multiple-testing family are fixed before broad parameter testing.

Use Massive MCP as the only default source-data path for Massive-backed inputs. If the required fixed research dataset is not already present and provenance-complete, have the primary thread use $massive-mcp-data-plane to acquire it, enforce the dated Basic entitlement boundary and current MCP schema, complete pagination, respect the declared test/cutoff dates, and seal an acquisition manifest before factor exploration begins. Do not refetch or broaden the dataset after seeing a result merely to improve the candidate.

Explicitly use subagents in order:
1) factor-researcher investigates the registered hypothesis against the fixed dataset and records every attempted variant without deciding promotion;
2) statistical-validator independently checks chronology, leakage, purging/walk-forward design where applicable, monotonicity, uncertainty, multiple-testing correction, parameter stability, regime dependence, turnover, pessimistic cost scenarios, OOS evidence, and consistency with the sealed acquisition provenance;
3) methodology-auditor performs a fresh adversarial review for survivorship/lookahead, post-selection inference, sample dependence, unsupported causal language, fabricated precision, data-capability violations, and Massive MCP acquisition/provenance defects.

The primary Codex thread must reconcile those artifacts, then run the deterministic promotion gate. Only the gate/state-transition code may write PROMOTED. Preserve rejected/inconclusive/invalid evidence. Do not broaden the hypothesis after observing results; register a new hypothesis/version for materially new research. If required evidence cannot be obtained under the current Massive Basic/MCP boundary, end with the strongest honest non-promotion state and state what would unlock further work.
```
